# 🐾 PawPerfect — інтернет-магазин зоотоварів

Статичний сайт (HTML + CSS + JavaScript), без збірки й залежностей.

## Можливості
- Головна сторінка та каталог із 30 товарів (3 категорії × 10)
- Картки товарів: фото, назва, опис, категорія, виробник, призначення, вага/об’єм, ціна
- Перегляд товару: клік по картці відкриває детальну сторінку з характеристиками та схожими товарами
- Додавання, редагування, видалення товарів (дані зберігаються в `localStorage`)
- Відгуки: оцінка зірками та текст до кожного товару, середній рейтинг на картках, добірка відгуків на головній (`localStorage`, ключ `pawperfect_reviews_v1`)
- Кошик і оформлення замовлення (замовлення зберігаються в `localStorage`, ключ `pawperfect_orders_v1`)
- Карта Google Maps («Як нас знайти») і контакти у футері (замініть телефон, e-mail, адресу та посилання на свої в `index.html`)
- Пошук за назвою, категорією, виробником; фільтр за категорією та ціною; сортування

## Структура
```
index.html
css/style.css
js/app.js
images/hero.webp          # фото тварин для головної (вирізане з білого фону)
images/products/*.jpg    # фото товарів
```

## Запуск
Відкрийте `index.html` у браузері.

## Публікація на GitHub Pages
1. Створіть репозиторій і завантажте всі файли в корінь.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Сайт буде доступний за адресою `https://<ваш-логін>.github.io/<репозиторій>/`.

## Адмін-панель
Вхід: `index.html#admin` або посилання «Вхід для адміністратора» внизу сторінки.
Початковий пароль: `pawperfect2026` — **змініть його одразу** у вкладці «Налаштування».

- Замовлення: пошук, фільтр за статусом, зміна статусу, видалення, експорт у CSV
- Товари: пошук, швидка зміна ціни, додавання, редагування, видалення
- Налаштування: зміна пароля

### ⚠️ Обмеження
Сайт статичний, без сервера. Пароль лише ховає інтерфейс (у коді зберігається хеш SHA-256), це не справжній захист.
Усі дані (товари, замовлення, відгуки) зберігаються в `localStorage` браузера, тому замовлення, зроблені
клієнтами на їхніх пристроях, **не потраплять** в адмін-панель на вашому пристрої.
Для реального магазину потрібен бекенд (наприклад, Firebase, Supabase або Google Sheets + Apps Script).
